FuguBSD

FuguBSD makes small tools in two areas: language models with agents for OpenBSD, and air-gapped tools that keep a secret safe.

FuguTTX is a small language model and agent for OpenBSD system administration. It runs on the CPU of a small machine, with no network. FuguVM gives an agent a real OpenBSD guest, and FuguBench gives it a workspace.

FuguSeed makes a seed phrase with dice on paper. FuguPass turns that seed phrase into a password manager, and FuguOracle guards each entry behind a PIN.

Each tool does one task, and states its design in a specification. The code follows the OpenBSD model, under the ISC license. OpenBSD is the production platform, and Linux and Darwin serve development and CI. All source code lives in the FuguBSD organization on GitHub.

Projects

Each project keeps its own website and its own repository.

Language models and agents

  • FuguTTX — a small language model and agent for OpenBSD system administration (source)
  • FuguCTX — a configuration repair model for OpenBSD daemons (source)
  • FuguSTX — find the tells of machine-written prose in English technical text (source)
  • FuguVM — install and manage OpenBSD virtual machines under QEMU, by hand or by agent (source)
  • FuguBench — outfit a FuguBSD checkout for a coding agent: dependencies, worktrees, the learning library, and the session yardstick (source)

Air-gapped security

  • FuguSeed — make BIP39 seed words with three dice on paper, and turn them into a SeedQR (source)
  • FuguPass — a password manager for any secret, with one 12-word seed phrase as the master key (source)
  • FuguOracle — a blind PIN oracle service that holds a key share for each client, and releases it to the correct PIN alone (source)

Shared tools

  • Fugu — generic OpenBSD-style daemon utilities for Perl (source)
  • FuguWeb — build a documentation website for a Perl project (source)
